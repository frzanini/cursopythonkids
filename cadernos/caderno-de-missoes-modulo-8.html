Ideia nova · criar e chamar

def boas_vindas(): cria uma função. O que está recuado embaixo é o que ela faz. Você já fez isso com a draw(), mas quem chamava a draw() era o Pygame Zero.

boas_vindas() chama a função: o Python vai lá e faz o que está dentro dela. Chamou duas vezes, ela faz duas vezes.

Rode!

No terminal aparece, duas vezes: Olá! e Vamos crescer como Jesus.

Agora acrescente, embaixo:

def dobro(numero):
    return numero * 2


print(dobro(5))
print(dobro(21))
Ideia nova · parâmetro e return

numero é um parâmetro: o valor que a função recebe entre os parênteses. Em dobro(5), ele vale 5.

return devolve o resultado para quem chamou. Por isso dá para pôr dobro(5) dentro do print.

Rode!

Aparecem mais duas linhas: 10 e 42.

Por último, a função que vai para o jogo:

def corrige_tunel(coluna):
    if coluna < 0:
        return 19
    if coluna >= 20:
        return 0
    return coluna


print(corrige_tunel(-1))
print(corrige_tunel(20))
print(corrige_tunel(7))

Saiu pela esquerda (-1)? Devolve 19. Pela direita (20)? Devolve 0. Senão, devolve a mesma coluna. O return também faz a função sair na hora: as linhas de baixo nem rodam.

Rode!

As últimas linhas são 19, 0 e 7.

Erre de propósito

Troque print(dobro(5)) por print(dobro), sem os parênteses: aparece algo como <function dobro at 0x...>. Sem os (), a função não é chamada.

Depois apague o return da dobro (deixe só numero * 2): o print(dobro(5)) mostra None, que quer dizer "nada". A conta foi feita, mas a função não devolveu. Desfaça as duas mudanças.

1

O túnel vira uma função

Volte para o jogo.py. Logo antes do def draw(): (fora de qualquer função, sem recuo), crie:

# ---------------- as nossas funções ----------------

def corrige_tunel(coluna):
    # Saiu por um lado? Devolve a coluna do outro lado. Senão, devolve a mesma.
    if coluna < 0:
        return COLUNAS - 1
    if coluna >= COLUNAS:
        return 0
    return coluna

Agora, no update(), troque cada um dos quatro túneis por uma chamada. Os três primeiros têm este formato (a direção muda em cada um):

        nova_coluna = personagem_coluna + proxima_direcao[0]
        nova_linha = personagem_linha + proxima_direcao[1]
        if nova_coluna < 0:
            nova_coluna = COLUNAS - 1
        if nova_coluna >= COLUNAS:
            nova_coluna = 0

e viram assim, sem os quatro if:

        nova_coluna = corrige_tunel(personagem_coluna + proxima_direcao[0])
        nova_linha = personagem_linha + proxima_direcao[1]

Faça o mesmo com o personagem_coluna + direcao[0] (o andar) e com o tentacao_coluna + opcao[0] (os caminhos livres). O quarto é o da tentação andando, que vira:

        tentacao_coluna = corrige_tunel(tentacao_coluna + tentacao_direcao[0])
        tentacao_linha = tentacao_linha + tentacao_direcao[1]
  • Esta função não precisa de global: ela só lê o COLUNAS, não muda nada lá fora.
Rode!

O jogo funciona igualzinho a antes, com túnel e tudo. A diferença está no código: os quatro túneis (16 linhas de if) viraram uma função. Se um dia precisar mudar o túnel, você muda num lugar só.

Igual à Fase 7. Leve o personagem até o túnel do meio: ele ainda atravessa.

A função que reinicia as posições

Logo depois da corrige_tunel, crie:

def reiniciar_posicoes():
    # Coloca o personagem e a tentação de volta no começo, parados
    global personagem_coluna, personagem_linha, direcao, proxima_direcao
    global tentacao_coluna, tentacao_linha, tentacao_direcao

    personagem_coluna = INICIO_COLUNA
    personagem_linha = INICIO_LINHA
    direcao = (0, 0)
    proxima_direcao = (0, 0)
    tentacao_coluna = TENTACAO_INICIO_COLUNA
    tentacao_linha = TENTACAO_INICIO_LINHA
    tentacao_direcao = (-1, 0)

Esta função muda variáveis de fora, então precisa do global. Agora use a função no on_key_down: troque o global e o if do espaço por estes (as quatro setas continuam iguais embaixo):

def on_key_down(key):
    global proxima_direcao

    if key == keys.SPACE:
        reiniciar_posicoes()

4

Encostar na tentação

Logo depois da reiniciar_posicoes, crie:

def verificar_encontro():
    # O personagem e a tentação estão no mesmo quadradinho? Perde uma vida.
    global vidas

    if (personagem_coluna, personagem_linha) == (tentacao_coluna, tentacao_linha):
        vidas = vidas - 1
        reiniciar_posicoes()
  • == entre dois pares compara os dois números de uma vez: mesma coluna e mesma linha.
  • Uma função pode chamar outra: a verificar_encontro chama a reiniciar_posicoes.

Agora chame a função em dois lugares do update(). Depois que o personagem anda (embaixo da coleta):

        if (personagem_coluna, personagem_linha) in habitos:
            habitos.remove((personagem_coluna, personagem_linha))
            estatura = estatura + PONTOS_POR_HABITO

        verificar_encontro()

E depois que a tentação anda (embaixo do túnel dela):

        tentacao_coluna = corrige_tunel(tentacao_coluna + tentacao_direcao[0])
        tentacao_linha = tentacao_linha + tentacao_direcao[1]

        verificar_encontro()
Por que nos dois lugares?

Se você só olhar depois que o personagem anda, a tentação pode andar para cima de você e ninguém perceber. Olhando depois de cada um andar, ninguém atravessa ninguém.

Rode!

Deixe a tentação te alcançar: uma bolinha some e os dois voltam para o começo. Depois da terceira vez, as bolinhas acabam... mas o jogo continua! Isso a gente arruma agora.

5

O fim de jogo

Logo depois das vidas, crie:

# Quando as vidas acabam, o jogo para e mostra a tela de fim de jogo
fim_de_jogo = False

Na verificar_encontro, ponha fim_de_jogo no global e, dentro do if do encontro, embaixo do reiniciar_posicoes(), acrescente:

def verificar_encontro():
    # O personagem e a tentação estão no mesmo quadradinho? Perde uma vida.
    global vidas, fim_de_jogo

    if (personagem_coluna, personagem_linha) == (tentacao_coluna, tentacao_linha):
        vidas = vidas - 1
        reiniciar_posicoes()
        if vidas == 0:
            fim_de_jogo = True

E no update(), logo depois das três linhas de global:

    if fim_de_jogo:
        return

O return também funciona numa função que não devolve nada: ele faz o update() sair na hora. Com o fim de jogo, nada mais anda.

Rode!

Perca as 3 vidas: na terceira, o jogo congela. Ninguém anda mais. Falta a tela.

def draw():

Ver uma dica

Crie uma função novo_jogo() que monta a lista habitos de novo (o mesmo for dentro de for), zera a estatura, devolve as vidas, desliga o fim_de_jogo e chama a reiniciar_posicoes(). Ela precisa de global para tudo isso.

No on_key_down, use um if dentro do outro: if key == keys.RETURN: e, dentro dele, if fim_de_jogo:.

def draw():

    if fim_de_jogo:
        desenhar_derrota()
        return

    screen.fill(COR_DE_FUNDO)

    # As paredes: passa por todas as linhas e, em cada linha, por todas as
    # colunas. Onde o mapa tem "#", desenha um quadrado.
    for linha in range(LINHAS):
        for coluna in range(COLUNAS):
            if MAPA[linha][coluna] == "#":
                parede = Rect((coluna * TILE, linha * TILE), (TILE, TILE))
                screen.draw.filled_rect(parede, COR_DA_PAREDE)

    # Os bons hábitos: uma bolinha no centro de cada quadradinho da lista
    for habito in habitos:
        x = habito[0] * TILE + TILE // 2
        y = habito[1] * TILE + TILE // 2
        screen.draw.filled_circle((x, y), 6, COR_DO_HABITO)

    # O placar (HUD): a estatura à esquerda e quantos hábitos faltam à direita.

    screen.draw.text(
        "Estatura: " + str(estatura),
        topleft=(10, 8),
        fontsize=28,
        color=COR_DO_TEXTO,
    )
    screen.draw.text(
        "Faltam: " + str(len(habitos)),
        topright=(WIDTH - 10, 8),
        fontsize=28,
        color=COR_DO_TEXTO,
    )

    # A lista ficou vazia? Então todos os hábitos foram coletados!
    if len(habitos) == 0:
        mensagem = "Parabéns! Você cresceu!"
    else:
        mensagem = "As setas escolhem o caminho!"

        mensagem,
        center=(WIDTH // 2, TILE // 2),
        fontsize=24,
        color=COR_DO_TEXTO,

    # A régua da estatura: um retângulo que fica mais comprido quanto mais

    regua = Rect((WIDTH - 400, HEIGHT - 28), (estatura // 3, 16))
    screen.draw.filled_rect(regua, COR_DA_REGUA)
    moldura = Rect((WIDTH - 400, HEIGHT - 28), (386, 16))
    screen.draw.rect(moldura, COR_DO_TEXTO)

    # As vidas: uma bolinha dourada para cada vida que sobrou
    for numero in range(vidas):
        screen.draw.filled_circle((250 + numero * 30, HEIGHT - 20), 9, personagem_cor)

    # Do quadradinho (coluna, linha) para os pixels do centro dele
    x = personagem_coluna * TILE + TILE // 2
    y = personagem_linha * TILE + TILE // 2
    screen.draw.filled_circle((x, y), personagem_raio, personagem_cor)

    # A tentação: um círculo com dois olhos que olham para onde ela vai
    x = tentacao_coluna * TILE + TILE // 2
    y = tentacao_linha * TILE + TILE // 2
    screen.draw.filled_circle((x, y), TILE // 2 - 4, COR_DA_TENTACAO)
    olhar_x = tentacao_direcao[0] * 2
    olhar_y = tentacao_direcao[1] * 2
    screen.draw.filled_circle((x - 6, y - 4), 5, "white")
    screen.draw.filled_circle((x + 6, y - 4), 5, "white")
    screen.draw.filled_circle((x - 6 + olhar_x, y - 4 + olhar_y), 2, "black")
    screen.draw.filled_circle((x + 6 + olhar_x, y - 4 + olhar_y), 2, "black")


def update():
    global quadros_personagem, personagem_coluna, personagem_linha
    global direcao, estatura
    global quadros_tentacao, tentacao_coluna, tentacao_linha, tentacao_direcao

    # Fim de jogo: o return sai do update() na hora, e nada mais anda.
    if fim_de_jogo:
        return

    # ---------------- o personagem ----------------
    quadros_personagem = quadros_personagem + 1
    if quadros_personagem == ESPERA_PERSONAGEM:
        quadros_personagem = 0

        # 1. Dá para virar para a direção que você escolheu? Então vira.
        nova_coluna = corrige_tunel(personagem_coluna + proxima_direcao[0])
        nova_linha = personagem_linha + proxima_direcao[1]
        if MAPA[nova_linha][nova_coluna] != "#":
            direcao = proxima_direcao

        # 2. Anda um quadradinho na direção atual, se lá não for parede
        nova_coluna = corrige_tunel(personagem_coluna + direcao[0])
        nova_linha = personagem_linha + direcao[1]
        if MAPA[nova_linha][nova_coluna] != "#":
            personagem_coluna = nova_coluna
            personagem_linha = nova_linha

        # 3. Parou em cima de um bom hábito? Ele sai da lista e você cresce
        if (personagem_coluna, personagem_linha) in habitos:
            habitos.remove((personagem_coluna, personagem_linha))
            estatura = estatura + PONTOS_POR_HABITO

        # 4. Encostou na tentação?
        verificar_encontro()

    # ---------------- a tentação ----------------
    quadros_tentacao = quadros_tentacao + 1
    if quadros_tentacao == ESPERA_TENTACAO:
        quadros_tentacao = 0

        # 1. Quais caminhos estão livres? Ela nunca dá meia-volta.
        meia_volta = (-tentacao_direcao[0], -tentacao_direcao[1])
        livres = []
        for opcao in DIRECOES:
            if opcao != meia_volta:
                nova_coluna = corrige_tunel(tentacao_coluna + opcao[0])
                nova_linha = tentacao_linha + opcao[1]
                if MAPA[nova_linha][nova_coluna] != "#":
                    livres.append(opcao)

        # 2. Sorteia um dos caminhos livres. No corredor só tem um;
        #    no cruzamento tem dois ou três, e o random escolhe.
        tentacao_direcao = random.choice(livres)

        # 3. Anda um quadradinho para lá (com túnel)
        tentacao_coluna = corrige_tunel(tentacao_coluna + tentacao_direcao[0])
        tentacao_linha = tentacao_linha + tentacao_direcao[1]

        # 4. Encostou em você?
        verificar_encontro()


def on_key_down(key):
    global proxima_direcao

    if key == keys.SPACE:
        reiniciar_posicoes()

    # As setas só ESCOLHEM a direção. Quem anda é o update().
    if key == keys.RIGHT:
        proxima_direcao = (1, 0)
    if key == keys.LEFT:
        proxima_direcao = (-1, 0)
    if key == keys.DOWN:
        proxima_direcao = (0, 1)
    if key == keys.UP:
        proxima_direcao = (0, -1)

Palavras novas

Função (a sua)
Um pedaço de código com nome, criado com def, que você chama quando quiser.
Chamar uma função
Escrever o nome dela com (), como reiniciar_posicoes().
Parâmetro
Um valor que a função recebe entre os parênteses, como o coluna de corrige_tunel(coluna).
return
Devolve um resultado para quem chamou e sai da função na hora.
None
"Nada": o que uma função devolve quando não tem return.
Vidas
Um contador que desce a cada encontro com a tentação.
Fim de jogo
Uma variável True/False que faz o jogo parar.
