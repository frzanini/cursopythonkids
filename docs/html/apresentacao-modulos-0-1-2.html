Módulo 0 · Organização

Arquivo, pasta, caminho e extensão

  • Arquivo: uma coisa guardada no computador (texto, foto, programa).
  • Pasta: uma "caixa" que guarda arquivos, para organizar.
  • Caminho (path): o "endereço" de um arquivo — pasta por pasta até chegar nele.
  • Extensão: a parte depois do ponto (.png, .py). Python termina em .py.

Módulo 1

Conhecendo a programação

Hoje: o primeiro programa e a primeira tela do jogo.

Módulo 1 · O jogo

O que vamos construir no curso

Um jogo de labirinto no estilo Pac-Man com a ideia de Lucas 2:52. O personagem anda pelo "labirinto da vida":

  • coleta bons hábitos — 🙏 oração, 📖 Bíblia, ⛪ culto, ❤️ obedecer aos pais, 🤝 ajudar — que aumentam a estatura;
  • desvia das tentações — 😡 desobediência, 🤥 mentira, 😴 preguiça, 📱 distração;
  • a oração é um poder: as tentações fogem por alguns segundos;
  • são 4 fases: Sabedoria → Estatura → Graça com Deus → Graça com os homens.
Módulo 1 · Objetivos

O que vamos aprender hoje

  • O que é um programa e um algoritmo
  • O computador executa uma instrução de cada vez, na ordem
  • O que é uma biblioteca e de onde vem o Pygame Zero
  • O que é uma variável
  • O que é uma função e por que o recuo (indentação) importa
  • Escrever e rodar o primeiro programa com Pygame Zero
Módulo 1 · Ideias

Programa, algoritmo e a ordem

  • Um programa é uma lista de instruções que o computador segue.
  • Um algoritmo é a sequência de passos — como uma receita de bolo.
  • O computador faz uma instrução de cada vez, de cima para baixo. Ele não adivinha nem pula na frente.

Numa receita, trocar "leve ao forno" com "misture os ovos" estraga tudo. No código é igual.

Módulo 1 · Passo 1

O esqueleto mínimo

import pgzrun

pgzrun.go()
  • import pgzrun — traz um código pronto de fora. Dá screen, draw() e o resto. Vai na primeira linha.
  • pgzrun.go() — liga o motor do jogo: abre a janela e fica redesenhando. Vai na última linha.

Rode: abre uma janelinha preta — já é um jogo Pygame Zero de verdade, só que vazio.

Módulo 1 · Passo 2

Tamanho e título da janela

WIDTH = 800
HEIGHT = 600
TITLE = "Crescendo como Jesus"
  • Variável: um nome que guarda um valor. WIDTH = 800 = "de agora em diante, WIDTH vale 800".
  • WIDTH e HEIGHT: tamanho da janela em pixels. TITLE: texto da barra.
  • O Pygame Zero reconhece esses três nomes sozinho — em maiúsculas.
Módulo 1 · Passo 3

Pintar o fundo — e a função draw()

COR_DE_FUNDO = "skyblue"


def draw():
    screen.fill(COR_DE_FUNDO)
  • Função: um pedaço de código com nome. draw() é especial — o Pygame Zero chama ela sozinho, várias vezes por segundo.
  • Indentação: o recuo não é enfeite, é regra. Ele diz "esta linha faz parte da função". Faltou → IndentationError.
Módulo 1 · Passo 4

A mensagem de boas-vindas

def draw():
    screen.fill(COR_DE_FUNDO)
    screen.draw.text(
        "Bem-vindo(a) ao " + TITLE + "!",
        center=(WIDTH // 2, HEIGHT // 2),
        fontsize=40,
        color=COR_DO_TEXTO,
    )
  • + junta textos. center=(...): onde o texto fica centralizado.
  • // é divisão inteira — WIDTH // 2 é o meio da tela.

Módulo 1 · exemplo.py

O código completo do módulo

import pgzrun

WIDTH = 800
HEIGHT = 600
TITLE = "Crescendo como Jesus"

NOME_DO_PECADOR = "Escreva seu nome aqui"
VERSICULO = '"Jesus crescia em sabedoria, estatura e graça..." (Lucas 2:52)'
COR_DE_FUNDO = "skyblue"
COR_DO_TEXTO = "white"


def draw():
    screen.fill(COR_DE_FUNDO)
    screen.draw.text("Bem-vindo(a) ao " + TITLE + "!",
        center=(WIDTH // 2, HEIGHT // 2 - 60), fontsize=40, color=COR_DO_TEXTO)
    screen.draw.text(VERSICULO,
        center=(WIDTH // 2, HEIGHT // 2 - 10), fontsize=20, color=COR_DO_TEXTO)
    screen.draw.text("Pecador: " + NOME_DO_PECADOR,
        center=(WIDTH // 2, HEIGHT // 2 + 40), fontsize=24, color=COR_DO_TEXTO)


pgzrun.go()

Módulo 2

O personagem e a primeira decisão

A tela de boas-vindas vira a primeira cena de verdade do jogo.

Módulo 2 · A ideia

Uma pergunta e uma resposta

Um personagem aparece; uma pergunta sobre um hábito cristão é feita ("Você orou hoje?"); o jogador clica em Sim ou Não.

O personagem reage: cresce e muda de cor no "Sim", fica igual ou menor no "Não" — a primeira "decisão" programada do jogo.

Módulo 2 · Objetivos

O que vamos aprender hoje

  • Coordenadas: onde algo fica na tela — um par (x, y)
  • Desenhar formas: um círculo e retângulos
  • Variáveis lógicas (True / False)
  • if / elif para o programa decidir, comparando com ==
  • Evento de clique: função que o Pygame Zero chama ao clicar
  • global: mudar, dentro da função, uma variável de fora
Módulo 2 · Passo 1

Coordenadas e o personagem parado

personagem_x = WIDTH // 2
personagem_y = HEIGHT // 2 - 60
personagem_raio = 40
personagem_cor = "gold"

    screen.draw.filled_circle(
        (personagem_x, personagem_y), personagem_raio, personagem_cor
    )

Coordenada: x cresce para a direita, y cresce para baixo. O (0, 0) é o canto superior esquerdo — diferente do caderno de matemática!

Módulo 2 · Passo 2

A pergunta na tela

PERGUNTA = "Você orou hoje?"

    screen.draw.text(
        PERGUNTA,
        center=(WIDTH // 2, HEIGHT // 2 - 160),
        fontsize=32,
        color=COR_DO_TEXTO,
    )

screen.draw.text(...) já apareceu no Módulo 1 — só muda a posição (bem acima do personagem).

Módulo 2 · Passo 3

Os botões Sim e Não

botao_sim = Rect((WIDTH // 2 - 160, HEIGHT // 2 + 120), (120, 50))
botao_nao = Rect((WIDTH // 2 + 40, HEIGHT // 2 + 120), (120, 50))

    screen.draw.filled_rect(botao_sim, "green")
    screen.draw.text("Sim", center=botao_sim.center, fontsize=28, color="white")
    screen.draw.filled_rect(botao_nao, "red")
    screen.draw.text("Não", center=botao_nao.center, fontsize=28, color="white")
  • Rect((x, y), (largura, altura)): canto superior esquerdo + tamanho.
  • botao_sim.center: o Rect calcula o ponto central sozinho.
Módulo 2 · Passo 4

Detectando o clique

def on_mouse_down(pos):
    if botao_sim.collidepoint(pos):
        print("clicou no Sim")
    elif botao_nao.collidepoint(pos):
        print("clicou no Não")
  • on_mouse_down(pos): função especial — o Pygame Zero chama sozinho a cada clique e entrega a coordenada pos.
  • retangulo.collidepoint(pos) responde True/False: "o ponto está dentro?".
Módulo 2 · Passo 5

Guardar a resposta e reagir — e o global

respondeu = False
resposta_foi_sim = False

def on_mouse_down(pos):
    global respondeu, resposta_foi_sim, personagem_raio, personagem_cor
    if botao_sim.collidepoint(pos):
        respondeu = True
        resposta_foi_sim = True
        personagem_raio = 60
        personagem_cor = "yellow"
    elif botao_nao.collidepoint(pos):
        respondeu = True
        resposta_foi_sim = False
        personagem_raio = 30
        personagem_cor = "gray"

Por que o global? Sem ele, a função só cria uma cópia local que some quando termina — e a tela nunca muda.

Módulo 2 · Passo 6

A mensagem de acordo com a resposta

    if respondeu:
        if resposta_foi_sim:

        else:
            mensagem = "Que tal fazer isso hoje?"

        screen.draw.text(

O if respondeu: só entra depois que algum botão foi clicado.

Módulo 2 · O fluxo do clique

O que acontece a cada clique

flowchart TB
    A["Clique na janela -> on_mouse_down(pos)"]
    A --> B{"pos dentro de botao_sim?"}
    B -- sim --> C["respondeu = True; resposta_foi_sim = True; cresce e fica amarelo"]
    B -- nao --> D{"pos dentro de botao_nao?"}
    D -- sim --> E["respondeu = True; resposta_foi_sim = False; encolhe e fica cinza"]
    D -- nao --> F["nada acontece (clicou fora)"]
